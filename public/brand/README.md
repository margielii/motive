# Reference-derived MOTIVE raster assets

These PNGs are crops of the owner's approved JPEG reference boards, **not original vector masters**. See `provenance.json` for crop coordinates (left, top, right, bottom) and source attachment hashes. The original boards are retained in `design/references`.

- Wordmark: primary MOTIVE wordmark from board 01, with only near-black background pixels made transparent. Letter and star geometry are retained from the reference; no font reconstruction or vector tracing.
- Icon: approved white rounded square/red four-point star from board 01, with the surrounding dark corner pixels made transparent. PWA 192/512 and Apple 180 PNGs are resampled versions of this crop.
- Artwork: clean square/thumbnail crops from board 08 for red seats, basketball, controller, night and dinner. No generated substitute artwork or gradients. Existing custom uploads take priority.

Limitations: JPEG compression and small source thumbnails limit sharpness, especially on Retina displays. Original SVG wordmark/icon masters and full-resolution category/group artwork remain unavailable. No exact Drink, Soccer or Gym artwork was supplied as standalone source images; existing approved crops remain available for selection and library icons identify categories. Fictional members retain initials until custom avatars are uploaded; original portrait masters were not supplied.
